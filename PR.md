# TWEAC PICMI production prototype (local integration branch)

This branch converts the active `tweac5DegreeSetup` to a Python PICMI definition. It contains twelve ordered reusable topics above local `dev`, followed by five commits for the reference setup, script, diagnostics, and migration record. It is an integration prototype, not a single proposed upstream PR. The twelve candidate PR descriptions are archived in [`pr-descriptions/`](pr-descriptions/), and [`REBUNDLING_REPORT.md`](REBUNDLING_REPORT.md) records their commit mapping and validation.

Run `tweac5DegreeSetup/picmi_setup.py OUTPUT_DIR` with the repository's Python package to generate input files. The default remains 1000 steps on the 3584 × 3584 × 1792 grid with 8 × 16 × 8 devices. It preserves the density, species, numerical settings, switching and moving windows, two incident-field TWTS pulses, precision settings, and all 27 active diagnostic objects. TWTS uses float64 internally with an eight-sigma cutoff while the core uses float32; injection is componentwise. Automatic grid adjustment is disabled, and progress is reported every one percent.

The Python script writes setup files only. Its checks cover conversion, rendered parameters, diagnostics, and comparison with the original reference and pinned source generation. No C++ compilation, simulation, device execution, or diagnostic-file production was performed. The typed ADIOS2 backend omits the ineffective `adios2.dataset.chunks="auto"` key. The longer-run density expression has the documented rounding qualification in [`README_PICMI.md`](tweac5DegreeSetup/README_PICMI.md).
